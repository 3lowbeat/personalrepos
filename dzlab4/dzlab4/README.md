# Домашнее задание к работе 4

## Условие задачи
Три груза (A, B, C кг) можно погрузить в контейнер, если вес каждого из них кратен пяти. Запишите условие, при котором диспетчерская система дает разрешение на погрузку.

## 1.Алгоритм и блок-схема
1.**Начало**
2.Получение значений масс грузов A, B, C
3.Проверка соответствию условию
4.Форматированный вывод сообщения в зависимости от результата проверки
5.**Конец**

## 2.Реализация программы
#include <stdio.h>
#include <locale.h>
int main()

{
	setlocale(LC_CTYPE, "RUS");
	// Объявление переменных
	int A;
	int B;
	int C;
	printf("	ДОСТАВКА ГРУЗОВ\n==================================\n");
	// Получение значений переменных
	printf("Введите массы грузов через запятую\n");
	scanf("%d,%d,%d", &A, &B, &C);
	// Проверка условия
	if (A % 5 == 0 && B % 5 == 0 && C % 5 == 0)
		puts("Диспечерская даёт разрешение на погрузку.");
	else puts("Диспечерская не даёт разрешение на погрузку.");
	return 0;

}
